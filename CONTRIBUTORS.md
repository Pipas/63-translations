# Contributors

63 is made in Portugal by a small group of people. This page is for the ones who worked on
words: translating, writing cards, and catching the things that read wrong.

**Everyone here is credited in the app.** The names on this page go on the in-game credits
screen when the language ships. Add yourself in the same pull request as your translation.

## Adding yourself

Add a row to the right table with your name and the language codes you worked on. Order
within a table doesn't mean anything, so append to the end.

If you'd rather not use your real name, a handle is fine. That's what goes in the app, so
put down whatever you want players to see.

The credits screen itself is built in the app's code, not from this file, so a maintainer
moves the name across when the language ships. You don't need to do anything beyond adding
the row. The labels on that screen (`63/` → `credits.*`) are translated like any other
string.
